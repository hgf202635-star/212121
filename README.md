# بوابة العطاء — HTML/CSS/JavaScript

تطبيق واجهة عربية RTL متجاوبة. طلبك بدمج CSS مع HTML مطبق في `index.html`، ويتضمن JavaScript مضمناً لتشغيل التفاعلات.

## التشغيل
افتح `index.html` مباشرة في متصفح حديث، أو شغّل `python -m http.server 8000` من المجلد ثم افتح `http://localhost:8000`.

## الموجود
- الرئيسية، دليل الجهات مع بحث وفلاتر وترتيب، المجالات، تفاصيل السجل، الأسئلة الشائعة، التقييمات، الاقتراحات، مركز رموز الأخطاء، سياسة الخصوصية وشروط الاستخدام.
- بحث debounce، فلاتر مجال/منطقة/حالة، مفضلة محلية، وضع ليلي، قائمة جوال، نوافذ تفاصيل الأخطاء، إشعارات، تحقق محلي من النماذج.
- كتالوج BA-100 إلى BA-140.
- حالات التحقق، وسجلات العرض كلها موسومة بوضوح كبيانات تجريبية.

## حدود مهمة
هذه نسخة أمامية فقط: لا توجد قاعدة بيانات أو API أو مصادقة أو لوحة إدارة محمية أو إرسال خادمي أو تحقق مباشر من الجهات والروابط. لا تعرض البيانات التجريبية كجهات حقيقية. النماذج لا تدّعي نجاح الإرسال. المفضلة والوضع الليلي قد يحفظان محلياً فقط.

## الانتقال للإنتاج
أضف API وقاعدة بيانات، مصادقة موثوقة وصلاحيات خادمية، سياسات RLS عند استخدام Supabase، مراجعة بشرية للمصادر، تحديد معدل الطلبات، مراقبة أخطاء منقحة، اختبارات تلقائية وسياسة خصوصية مكتملة. لا تضع أسراراً في الواجهة.


## تحديث التصميم والهوية
- `logo-bawabat.png`: الشعار المرفق.
- `banner-bawabat.png`: صورة البنر المرفقة.
- الصفحة الرئيسية لا تعرض بحثاً أو بطاقات منصات؛ التنقل أصبح عبر قائمة جانبية.
- أضيفت حركات CSS خفيفة مع احترام `prefers-reduced-motion` وبيانات SEO الأساسية.
- عدّل رابط `canonical` و`og:image` إذا تغير نطاق النشر.
- لتحسين SEO الكامل، أضف `robots.txt` و`sitemap.xml` إلى جذر النشر وتأكد أن كل المسارات لها URLs فعلية؛ هذا الملف الحالي تطبيق أحادي الصفحة يستخدم hash routes.
